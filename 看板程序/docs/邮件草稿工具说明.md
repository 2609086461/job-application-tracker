# QQ邮件草稿工具

双击 `秋招投递/常用入口/创建QQ邮件草稿.bat`，依次填写收件人、主题和正文。正文输入完成后，单独输入一行 `.` 并按回车，邮件会保存到QQ邮箱草稿箱，不会发送。

也可以在 `看板程序` 目录中使用：

```powershell
.venv\Scripts\python.exe -m tools.mail.create_qq_draft `
  --to "hr@example.com" `
  --subject "邮件主题" `
  --body-file ".\邮件正文.txt"
```

只检查参数、不连接邮箱：

```powershell
.venv\Scripts\python.exe -m tools.mail.create_qq_draft `
  --to "hr@example.com" `
  --subject "邮件主题" `
  --body "邮件正文" `
  --preview
```

授权码沿用投递看板现有配置，从Windows凭据管理器读取，不会写入脚本。脚本仅通过IMAP写入草稿箱，不包含发送邮件的功能。
